# Retail Sales Dashboard (Power BI)

An interactive Power BI dashboard analysing 1,951 retail orders from
January to June 2015.



![RETAIL SALES DASHBOARD](https://github.com/user-attachments/assets/44d8f640-a0e2-41a5-9fb1-7433f09de00f)




## Tools
Power BI Desktop, Power Query, DAX

## What I did
- Cleaned the data and fixed column types in Power Query
- Built a Calendar table and a relationship to Orders
- Wrote DAX measures: Total Sales, Total Profit, Profit Margin %,
  Total Orders, Total Customers, Return Rate %
- Built KPI cards, trend, region, category, segment and state visuals
- Added slicers for Region, Product Category and Month

## Key insights
- Sales $1.92M, profit $224K, margin 11.67%
- South region is loss-making (-$14K) despite $354K sales
- Technology leads sales; Office Supplies leads profit
- Tables lose the most (-$7.2K); Binders earn the most ($59K)
- January and March profit were near zero
- California and New York are the top states
